📝 Petunjuk Login

  1. Buka browser (Chrome, Firefox, Safari, atau Edge)
  2. Masuk ke URL: https://simkur.smkpgriblora.sch.id/login
  3. Masukkan Username sesuai tabel di atas
  4. Masukkan Password: password
  5. Klik tombol "Masuk"

⚠️ KEAMANAN & PERUBAHAN PASSWORD - PENTING!

  1. Password default adalah password untuk semua akun
  2. SEGERA GANTI PASSWORD setelah login pertama kali
  3. Gunakan menu "Ganti Password" di profil Anda
  4. Gunakan password yang kuat dan unik:
    • Minimal 8 karakter
    • Kombinasi huruf besar, huruf kecil, angka
    • Jangan gunakan informasi pribadi yang mudah ditebak
  5. JANGAN BAGIKAN username dan password kepada orang lain
  6. Logout setelah selesai menggunakan aplikasi
